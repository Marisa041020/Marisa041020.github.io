# ==========================================================
# 照片描述
# ----------------------------------------------------------
# 两种写法，任选其一：
#
#   ① 直接写进文件名（最省事，上传时顺手写）
#        名字__描述.webp
#        例：2026-11-11-窗台上的两本书__下午的光斜过来.webp
#
#   ② 写在这个文件里（事后补，不用改文件名）
#        文件名 | 描述
#        例：2026-11-11-窗台上的两本书.webp | 下午的光斜过来
#
# 两处都写时，以这个文件为准。
# 不写描述的，只显示图片。
# 文件名不区分大小写、空格随便；可以不写扩展名。
# 「#」开头的行是注释，不会显示。
# ==========================================================

# 举例（把下面几行改成你自己的文件名）：
# 2026-11-梧桐-01.webp | 秋天操场边的那棵树，叶子黄了一半
# 2026-12-雪后操场.webp | 早自习前，没有人踩过的操场
