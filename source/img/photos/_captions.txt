# ==========================================================
# 照片描述
# ----------------------------------------------------------
# 一行一张，格式：文件名 | 描述
#   - 描述可以留空（只写文件名，或整行不写），那就只显示图片
#   - # 开头的行是注释，不会显示在网页上
#   - 写了但找不到对应图片的，构建时会给出提示
# ==========================================================

# 举例（把下面两行改成你自己的文件名）：
# 2026-11-梧桐-01.webp | 秋天操场边的那棵树，叶子黄了一半
# 2026-12-雪后操场-01.webp | 早自习前，没有人踩过的操场
